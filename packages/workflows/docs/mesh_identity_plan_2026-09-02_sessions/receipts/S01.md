Session S01, 2026-09-02/03. All paths relative to `/home/zygomatic/Zygomatic Full/agents/crews/`.

## 0. Headline

`generate_vace_static_clip` now takes `control_dir=`, and a per-frame geometry sequence has
reached a GPU render for the first time. Measured on S02's registry plates, the correct
plate **beats both nulls on identity** — 0.7292 against 0.6993 (neutral) and 0.4209 (the
same poses on Cornelis' body). It **loses on frame-200-style edge correlation**, so the
gate as written is a **FAIL**; the edge half of that gate is shown below to be a motion

measure. Nothing was tuned.

## 1. What was built

### `control_dir=` on `generate_vace_static_clip`
`wan_vace_service.py`. New signature entries `control_dir=None, control_blend=None`
(before `log_fn`; every caller in the tree passes by keyword — grepped). Node 13 has always
been `LoadImagesFromFolderKJ` and could always read any folder; what did not exist was a
way for a caller to hand one over.

New module-level functions, all fail-safe (any failure logs and falls back to the channel
the run would have built without the argument):

| function | what it does |
|---|---|
| `control_frames_in(dir)` | plate frames in render order: `ctrl_*`, `c_*`, `frame_*`, then `*.png` |
| `build_control_from_dir(...)` | pad/truncate to `num_frames` (same rule and wording as `build_mask_sequence`), resize to render size, blend, write the run's `_vace_ctrlseq/` |
| `paint_control_frame(...)` | the prop-plate + character-geometry block, lifted out of the single-image branch into one function |
| `paint_control_sequence(...)` | applies it to EVERY frame of a control sequence |
| `stamp_control_channel(...)` | `_vace_control_stamp.json` + a `run_logbook.record_metrics` row (LOGBOOK.md) |

`control_blend` (env `ZYG_VACE_CTRL_BLEND`) is `mask` by default:
`ctrl_t = still*(1-m_t) + plate_t*m_t`. A depth plate is a full-frame raster on black;
handing that in raw would pin a black set, so `raw` is opt-in and guarded. Works with a
single-PNG mask (repeated per frame, node 15 unchanged) and with `ZYG_VACE_MASK_SEQ=1`.

### Where painting happens now
Before: `prop_plates` (`:1579-1592`) and `ZYG_CHAR_GEOM_CTRL` (`:1606-1618`) were
`if neutral_control:` single-image children — structurally unreachable in exactly the mode
that has per-frame control. Now both run through `paint_control_frame()` once for the
single image (same output filenames `_vace_control_props.png` / `_vace_control_char.png`,
same log lines) and through `paint_control_sequence()` for every frame whenever
`control_dir` or sequence mode is active.

`geom/char_vace.py` gained `CharGeometryPainter`: MediaPipe detection is a property of the
STILL, so it runs once in `__init__` and paints many frames; `composite_char_geometry()` is
a one-shot wrapper over it.
**Regression, measured:** old module vs new, same still/control/mask, sha256 of the written
PNG `f312b604c83a71ee153eaaf673e2ff364571d2c8626dab2e0176da0459e4035a` on both — identical.
Per-frame run on 41 frames: `PER-FRAME PAINTING: 41/41 control frames carry geometry`.

|---|---|
| missing dir / empty dir | `no control frames found` → falls back to the old channel |
| all-black plates, `blend=raw` | refused: `41 control frames are near-black (mean<4) while the still is not` |
| all-black plates, `blend=mask`, full-white mask | refused, same guard |
| 5 plates for 41 frames + one corrupt PNG | padded to 41, corrupt frame held the previous plate, 41 on disk, min frame mean 36.54 — **no black or missing frame** |

### GATE: **FAIL** as written. Split by half:
| half | result |
|---|---|
| identity: correct > neutral | **PASS** 0.7292 > 0.6993 |
| identity: correct > wrong | **PASS** 0.7292 > 0.4209 |
| edge_corr(last): correct > neutral | FAIL 0.4759 < 0.6466 |
| edge_corr(last): correct > wrong | FAIL 0.4759 < 0.6710 |

**The identity half passes on both nulls, and the wrong-body margin is large** (−0.308 for
putting the right poses on the wrong body). That is the strongest available evidence that
the control channel is read: a plate that was ignored could not cost 0.31 of face cosine by
changing whose body is in it.

### The edge half is a motion proxy here — measured, not asserted
Edge r at the last frame ranks against the subject's tracked path length at Spearman
**−0.800** (Pearson −0.955) on these four arms and **−0.683, p=0.042** pooled over all nine
arms rendered this session. On a locked-camera clip whose null is nearly frozen,
"correlates with frame 0" and "did not move" are the same number, and the correct plate is
the arm that moves most (9.27 px path vs 4.35 neutral). Identity is not confounded that way
(identity vs path: Spearman +0.400, p=0.60 here; −0.100, p=0.87 on run B).

So: the gate is not passed, and it also cannot be evaluated with this metric. It needs a
late-frame fidelity measure that is not a motion proxy — masked structural similarity
against the plate's own silhouette, say — before "the plate holds structure" is answerable.
No parameter was changed to chase it.

### Four-state ledger
- identity, all four arms: `found`.
- edge_corr **frame_80 and frame_200: `not_detectable`** on every arm — a 41-frame clip has
  no frame 80. The frames the "prop fidelity ~0 by frame 80" finding is about were not
  reachable at this clip length; frame_mid (20) and frame_last (40) are the analogue this
  clip can carry and are **not the same measurement**.
- edge_corr frame_mid / frame_last: `found`. `unmeasurable`: none. `not_found`: none.

## 6. Not done, and why

- **`generate_vace_clip_from_frames` did not get a `control_dir`.** Its `frames_dir`
  argument already IS the per-frame control channel (`input_frames`); an alias would be a
  second name for one thing. Brief marked it optional. Its restore-tuned defaults are unchanged.
- **No long-clip run**, so frames 80/200 stayed `not_detectable`. 41 frames is what the
  plate tracks hold; padding to 205 would freeze the plate for 80% of the clip.
- **No seed sweep.** Every number is n=1 per arm. This is the main limit on §4.
- **The edge-correlation gate was not replaced**, only shown to be confounded. Designing a
  motion-independent late-frame fidelity metric is outside this brief.
- **A mistake worth recording:** I checked for S02's plates at session start, found nothing,
  and ran the fallback. They landed at 07:49, ~1 h before my re-run, and I only re-checked
  at write-up. Receipt A cost an extra four renders that a re-check before each GPU batch
  would have saved. "Verify state before building" has to mean *before each batch*, not once.
