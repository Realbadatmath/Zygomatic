## Why this session exists
Every studio "3D" preview is a textured plane in an orbit scene (Character CS3 `inspection.html:7816-7831`, Creature CRST3 `:10190-10205`, Movement MVST3 `:11179-11186`). The Mesh tab is read-only: two GET routes (`kanban_server.py:4598`, `:4600`); derive, reissue and gating are CLI-only, and the server runs in the agents venv, which cannot import Anny. Movement Studio's MISSING block (`movement_studio.py:1071-1095`) records the absence of prop plates, pose and depth plates, a driver-clip picker and per-frame masks; the `prop_plates` kwarg exists on `generate_vace_static_clip` (`wan_vace_service.py:1396`, consumed `:1579-1592`) and `bp_movement.py` never passes it; the object picker hands the render only `previews[0]` (`kanban_server.py:222-236`). `mesh_control.py` has zero consumers. Character Studio's Body placeholders (proportions, shoulders, waist, hands, feet, neck, bodyfat) ARE the Anny axes the Mesh card already displays (`inspection.html:7495-7499`); `poseref` is read-only (`character_studio.py:159`).
