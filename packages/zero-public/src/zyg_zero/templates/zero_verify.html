Check it yourself

Trust is a property of the verifier, not of the file, so our root certificate is public: /.well-known/zygomatic-c2pa-root.pem. Add it as a trust anchor in c2patool, or in the Content Credentials verify site, and a Zygomatic file reads as trusted rather than merely valid. Only the root is published — the signing key never leaves the studio. 

c2patool FILE --trust-anchors zygomatic-c2pa-root.pem
