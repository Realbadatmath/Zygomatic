    Control Settings

    Master catalogue of every guardrail, quality gate, parameter, and content policy rule enforced across Medusa, Creator Nexus, the port-5000 platform core, and all pipeline workflows — each entry has a unique ID, its file location, and whether it is currently active, so the roster can be individually verified and kept up to date. Protected by its own password, separate from your dashboard login.

    No Control Settings password exists yet. Choose one now. It is stored only as a salted, 600,000-round PBKDF2-SHA256 digest — nobody, including the AI assistant, can retrieve it afterward. There is no in-app recovery if you forget it.

    Azure Cloud Integrations

    All services are opt-in — toggle each one on only when you have credentials. A budget guard automatically stops calls at 95% of each free tier limit so you never get charged. Usage resets on the 1st of each month.

    Free-Tier Usage This Month

    Neural TTS (Speech) Free: 500K chars/month

    Narration for all pipelines (IndexTTS-2, Chatterbox fallback). Disable for silent placeholder audio.

    Blob Storage Free: 5 GB + 50K ops/month

    Upload finished videos/images to Azure after each job completes. Returns a Blob URL stored with the job.

    Event Grid Free: 100K events/month

    Publish a JobCompleted event whenever a pipeline job finishes. External systems can subscribe and react.

    Azure Functions Free: 1M calls/month

    Cloud entry point for external webhooks. External systems hit the Function URL; it validates and forwards requests to your pipeline.

    API Management Portal-only Free: 1M calls/month

    APIM is configured entirely in the Azure Portal — no credentials needed here. Set it up to proxy your zero_public_server URL with subscription-key auth and rate limiting. APIM calls are counted in the budget meter above once you add the policy.

    Credentials are stored locally in data/runtime/azure_config.json on your server — never sent to any third party. Secrets are masked in the UI after saving.

    🤗 HuggingFace Connection

    Your HuggingFace token is stored in .env as HF_TOKEN and applied immediately to the running server. It is used to download model weights (IPAdapter, LoRA base models, etc.) from private or gated repos.

    Get a free token at huggingface.co/settings/tokens — a Read token is sufficient.
