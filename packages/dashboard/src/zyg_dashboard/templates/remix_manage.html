Narration floor: no platform publishes a percentage — YouTube's monetization bar is qualitative ("significant original commentary") and the 10 % / 30-second fair-use rules are myths. The floor only guarantees every clip carries recurring spoken commentary (hook → insight → outro). Review flagged clips before uploading; compilations get a narrated intro, per-segment transitions and an outro for the same reason.
